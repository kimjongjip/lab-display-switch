# 검증 범위

`scripts/build.ps1 -Test`는 로직/인터롭 구조/DPI/프로필/복구 조건을 검사하며 드라이버
설치나 화면 전환을 하지 않습니다. 일반 CI는 이 명령만 실행합니다.

다음은 실제 바탕 화면을 변경하므로 일반 CI에서 실행하지 않습니다:

- `-WindowIntegration`: 테스트 창 생성/이동
- `--trial 20 --output artifacts\trial.json`: 실제 화면 숨김, 가상 화면 전환, 자동 복귀
- `scripts/test-tray-hotkeys.ps1 -AppPath '설치된 exe의 절대 경로'`: 실제 키로 숨김/복귀.
  연구실 모드와 이미 검증한 원격 설정이 필요하며 별도 구조 프로세스를 둡니다.

호스트 캡처 벤치마크/DXGI 진단은 실제 원격 전체 지연이나 클라이언트 성공의 증거가 아닙니다.
새 PC에서는 출력 수/위치/방향/DPI, 원격 입력/재접속, 확인 기한 만료 복귀, 확인 후 숨김
유지, Home/End, 일반/최대화/최소화 창, 마우스 분리/재연결을 각각 확인합니다.
프로세스 종료/장치 재시작/재부팅 고장 주입은 별도 계획 없이 실행하지 않습니다.

## 과거 검증과 공유 준비 변경

개발 PC의 Windows 11 Home x64/NVIDIA/혼합 DPI 두 화면에서 숨김/복귀, 자동 rollback,
창 복원, QHD 2개, 가로+세로 실제 화면과 가로 2개 원격 화면을 확인했습니다.
Mac Chrome 원격에서 커서 수정 후 사용자가 개선을 확인했습니다. 타 GPU 검증은 아닙니다.

1.0.5 공유 준비에서는 GPU 하드코딩 제거, 로컬 설정 도구, 버전 경로 일반화와 문서화를
수행했습니다. 이 변경 때문에 개발 PC의 앱/드라이버를 재설치하지 않습니다. 새 GPU의
설치·캡처·성능 검증은 대상 PC에서 진행해야 합니다. 개인별 기록은 artifacts에만 둡니다.
